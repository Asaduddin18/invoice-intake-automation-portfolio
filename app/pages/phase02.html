What happens in this phase

  1. Read known invoice data

    Use the supplied PDF's expected values, so model errors cannot obscure accounting integration errors.

  2. Validate the business facts

    Check supplier identity, dates, GBP currency, quantities, line calculations and totals with Decimal arithmetic.

  3. Check live mappings

    Confirm the UK demo's active expense account and purchase-tax code before any write.

  4. Resolve the supplier

    Use the seeded external contact number and Xero ContactID. Ambiguous matches stop for investigation.

  5. Create a draft, then retrieve it

    Send an ACCPAY bill with DRAFT status. Read it back by InvoiceID and compare fields, lines and totals.

  6. Repeat safely

    The live repeat and post-restart repeat returned the same bill ID. Uncertain writes hold for reconciliation.

What you should learn

ACCPAY
A supplier bill: money the business owes.
ContactID
Xero's exact supplier reference.
InvoiceNumber vs InvoiceID
The supplier's document reference versus Xero's record identifier.
Account code + tax type
Where a cost is recorded and how tax is calculated. The PDF usually cannot supply the business's account code.
Draft
A saved proposed record. No payment or bill authorization occurred.

Evidence and limits

  • 31 automated tests passed.
  • Live supplier creation and draft creation passed.
  • Retrieved fields and totals matched.

Validate it yourself

  1. Open the source PDF and calculate the two net lines and 20% tax.
  2. Open the Xero record. Compare supplier, dates, reference, quantities, unit prices, accounts, tax and total. Leave it in Draft.
  3. Use Preview or verify again, then submit. Expect reused_existing: true and the same InvoiceID.
  4. Explain why account 325 is a business mapping rather than an extracted invoice field.

What went wrong, and what changed

The modern Xero homepage and bill list stalled on a frame timeout. The classic purchase overview showed one draft for £95.16; Xero's documented organization-specific bill link then opened the complete record for inspection.

An exploratory script also used an incorrect organization-response lookup key. The implementation uses the correct response shape and its live preview passed.
