# Portfolio release sign-off

Scope: a local supplier-invoice workflow and a public illustrated replay using fictional data. The connected backend remains localhost-only.

Delivered: Gmail intake; page-aware DeepSeek extraction with bounded vision fallback; deterministic validation; configurable approval and correction history; duplicate-safe Xero drafts with reconciliation; independent monthly Sheets reporting; 50 searchable synthetic PDF fixtures and their generator; source, architecture, privacy, recovery and pilot documentation.

The public walkthrough is a replay, not a hosted accounting integration. The development evidence includes 20 selected model-evaluated PDFs and a five-arrival live Gmail acceptance run. Original and duplicate shared one previously created GBP 95.16 draft; two invalid invoices stayed held and one text file was unsupported. Repeat polling and reporting recovery added no model calls or creation intents.

Release checks and publication URLs are recorded in `artifacts/public/release-verification.json`. Account-linked development screenshots and full development history are excluded from the public snapshot. No production compliance, production accuracy, scan support or commercial time-saving claim is made.

Future client work requires agreed data permissions, deployment/authentication, managed secrets, monitoring, retention and representative acceptance tests. Payments, bill authorization and banking changes are outside this project. A license for third-party reuse has not been selected.

The portfolio project is signed off within this scope. The public repository and reachable walkthrough are recorded in the release verification. New client deployments and feature extensions are separate work.
