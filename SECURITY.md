# Security

This is a local synthetic-data portfolio demonstration. Do not expose its connected API to the internet or submit real client invoices without a separately agreed deployment and data-processing scope.

Never commit `.env`, `.runtime`, OAuth tokens, encryption keys or client records. The hosted walkthrough contains only fictional fixture data and has no connected backend.

For a suspected credential leak, revoke/rotate the affected provider credentials before cleaning history. For vulnerabilities, use a private channel on the author's GitHub profile when available. Do not post credentials, invoice contents or token files in public issues. There is no guaranteed support or response SLA.

See [privacy and retention](docs/privacy.md) and [operations](docs/operations.md).
